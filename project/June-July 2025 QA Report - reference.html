Key Digital and FTS Challenges & Highlights

AOS 2025.7

  • Approval Names Changed (Digital Fox S&E Direct): Script failed due to modified approval names in the "Deal Workspace > Approval Window".
  • Billing Terms (Digital Fox S&E Direct): Script needed updates to handle "Net 30 or Prepay" billing terms, as incorrect selection caused auto-rejection.
  • New Requirement (Digital Fox S&E Direct): A new rule, "FNB - Auto Rejection: Inventory not checked within 1 hour of submission" was added, requiring a script update to calculate inventory.
  • Mandatory Fields (Digital Fox S&E PRG): Several auto-rejections were observed as fields were made mandatory, necessitating script updates.
  • Product/Package Name Changes (FTS): The script needs to be updated to select products/packages with new Xpaths due to changes in their names in the Product Chooser.

AOS 2025.6

  • New fields added (General): New fields were added to the Deal Workspace, causing the xpaths of other fields to change and scripts to fail.
  • Global Default Organization (Digital Tubi and Direct): This challenge involved a change to the Global Default Organization to Big Ten Network and vice versa.

AOS 2025.3

  • Existing products and packages not set up (Digital Fox S&E): The script was modified to add products/packages as provided by Kevin.

AOS 2025.1

  • Digital Ratecards is blank (Digital Fox S&E): A change was needed in the script to select a different Primary AE for the Digital Ratecard to show up.
